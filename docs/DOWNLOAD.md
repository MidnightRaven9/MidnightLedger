# Download MidnightLedger

## Android

Download the latest APK from [GitHub Releases](https://github.com/MidnightRaven9/MidnightLedger/releases/latest). Your browser or file manager will ask you to allow installation from unknown apps. The APK is debug-signed for sideloading and needs no internet connection at runtime.

## PWA

The web app works on iPhone and Android without an install file.

1. Open the [live demo](https://midnightledger.justicegraff6.workers.dev).
2. On iPhone, use Share → Add to Home Screen.
3. On Android, use the browser menu → Install App.

It installs as MidnightLedger with the app icon.

## Privacy

The app builds from the source in this repository. All data is kept in local storage on your device; the app makes no network requests. Android builds disable OS backup, so clearing app data or uninstalling removes everything permanently.
